Remarks

The internal clock of the LPC1114 microcontroller is only accurate to ±1% over the temperature range of -40º C to +85º C.

The timer services provided by this class are very complicated, in order to support all of the features of the LPC1114 32-bit hardware counter/timers. You will need to carefully study the LPC11xx User Manual in order to fully understand how the counter/timers work.
