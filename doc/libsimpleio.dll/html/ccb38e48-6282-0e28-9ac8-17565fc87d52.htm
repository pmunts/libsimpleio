Using motor driver output C requires soldering wires from J1 pin 7 (akaPWMC) to J6 pin 2 and from J1 pin 11 (akaDIRC) to J6 pin 1.
Using motor driver output D requires soldering wires from J1 pin 16 (akaPWMD) to J8 pin 2 and from J1 pin 18 (akaDIRD) to J8 pin 1.
