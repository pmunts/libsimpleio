server  String  (Optional)

Indicates the communication protocol and host name (Domain name or IP address) of the network server with an attached LPC1114 I/O Processor, of the form [protocol]://[host].

The following network communication protocols are supported:

http ( Hypertext Transfer Protocol),
oncrpc ( Open Network Computing Remote Procedure Call), and
xmlrpc ( XML Remote Procedure Call).

The additional special string ioctl://localhost indicates the LPC1114 I/O Processor is attached directly to the computer the calling program is running on, either to an SPI ( Serial Peripheral Interface) peripheral bus, or to an I2C (Inter-Integrated Circuit) peripheral bus.

Remarks
The underlying library libspiagent.so only supports a single transport connection to a single LPC1114 I/O Processor at a time.
