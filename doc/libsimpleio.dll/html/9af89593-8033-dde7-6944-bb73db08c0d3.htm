Remarks

This class is only usable when the host computer (e.g. Raspberry Pi) is directly connected to the LPC1114 I/O Processor.

The host computer (e.g. Raspberry Pi) interrupt input GPIO pin that will be driven by the LPC1114 I/O Processor interrupt output GPIO pin must be defined by the LPC1114_INT variable in the configuration file /usr/local/etc/expansion_lpc1114.config.
