libspiagent Class

Thin binding class for libspiagent.so, the C driver library for the MUNTS-0004 Raspberry Pi LPC1114 I/O Processor Expansion Board, the LPC1114 I/O Processor Grove Module, and other boards.

These boards all have an LPC1114 32-bit ARM single chip microcontroller running firmware (the "SPI Agent") that acts as an I/O processor for another computer. A host computer board such as a Raspberry Pi or an Arduino (the "Master") can send commands to the LPC1114 I/O Processor (the "Slave") via an SPI ( Serial Peripheral Interface) peripheral bus or an I2C (Inter-Integrated Circuit) peripheral bus.
