Remarks

All PWM outputs share the same pulse frequency.

You must set the common PWM output pulse frequency (i.e.IO.Objects.LPC1114IOP.PWM.Output.frequency = 1000;) before configuring an H-Bridge DC motor driver output.

Certain motor driver modules such as the Cytron MD13s can driven by direction and speed signals. Most will require some form of motor driver signal transcoding such as the MUNTS-0005 PWM Isolator/Encoder module.
